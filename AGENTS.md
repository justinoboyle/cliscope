# Repository instructions

Use the [maintenance skill](.agents/skills/cliscope-maintenance/SKILL.md) for
application, packaging, test, and documentation changes in this repository.

- Follow [engineering requirements](docs/engineering.md) and
  [writing rules](docs/style.md).
- Keep each behavior, rule, and procedure in one owner; link to it elsewhere.
  Executable configuration is authoritative. Do not copy its settings into prose.
- Record reviewed changes in the [audit](docs/audit.md), linking measured evidence
  and security findings to their respective reports.
- Follow the [release procedure](docs/releases.md) for release code and merges.
